# Bijie blind test: pre-registered evaluation plan (written 2026-10-22, before the data were downloaded)

Purpose. Reviewers 2 (comment 1), 3 (comment 1) and 1 (comment 2) ask for an evaluation of the frozen pipeline on data not used during development. Every external set touched so far (GDCLD validation tiles and test scenes, GVLM) was scored with reference labels during development, so none qualifies. The Bijie landslide dataset (Ji, Yu, Shen, Li and Xu, Landslides, 2020; GPCV, Wuhan University) was never downloaded or used during development. This file fixes the evaluation before the data are seen. Its md5 is recorded in `results_night1.md` at the time of writing.

Data. One download of `https://gpcv.whu.edu.cn/data/Bijie_landslide_dataset.zip` to the training machine. All 770 landslide images with their masks and all 2003 non-landslide images (empty masks) are used, RGB only (no DEM), each with GSD 0.8 m as reported for the TripleSat imagery. No image is removed, inspected for selection or re-labelled. Mask pixels > 0 are landslide.

Configuration (frozen). Code as installed on the training machine on 2026-10-22 (`cas/train.py` md5 aa3faf49…, `cas/train_uda.py` md5 1c25d925…), with the default target-padding behaviour (no `--tgt_pad_ignore`). Every adaptation flag is copied from the main-table SCALAR runs (`C_sat2uav_M1ST_asym_p05n15_s0` and `C_uav2sat_M1ST_asym_p15n05_s0`); only the split, the index, the anchor and the side of the asymmetric margins change, and those follow the rules of Section 2: anchor = the source grid spacing nearest the target median (log distance), bounds [1/4, 2], r = target median / anchor, wider margin on the negative side for r > 1 and on the positive side for r < 1, transductive adaptation on all target images, checkpoint selected on the source validation split, inference at threshold 0.5.

Transfers (both pre-registered, both reported).
- T1, CAS SAT → Bijie. Source and validation = the SAT source split of the main SAT→UAV protocol (`splits/C_sat2uav.json`). Source spacings 0.5, 0.6, 3, 4, 5 m; nearest to 0.8 m is 0.6 m → anchor 0.6 m, r = 1.33 > 1 → margins (1.5δ, 0.5δ) as in UAV→SAT. The anchored source model is retrained at 0.6 m with the main source recipe (`C_sat2uav_M1_g0.5_s*` with `gsd_target = 0.6`). Native source model = `C_sat2uav_segformer_b2_s0`.
- T2, CAS UAV → Bijie. Source and validation = the UAV source split of the main UAV→SAT protocol (`splits/C_uav2sat.json`). Source spacings 0.2, 0.5, 0.6, 1 m; nearest to 0.8 m is 1 m → anchor 1 m, r = 0.8 < 1 → margins (0.5δ, 1.5δ) as in SAT→UAV. Anchored source model = the existing `C_uav2sat_M1_g1.0_s*`. Native source model = `C_uav2sat_segformer_b2_s0`.

Models and seeds. For each transfer: native source (seed 0), Source + GSA, GSA + LOC and SCALAR, seeds 0, 1 and 2.

Outcomes. Primary: pixel-pooled IoU at 0.5 over all 2773 images, SCALAR − Source + GSA, per transfer, mean and per seed. Secondary: the GSA, LOC and RSR steps; IoU over the 770 landslide images; false-positive pixel fraction on the 2003 non-landslide images; average precision; zero-shot precision and recall of the anchored source model.

Expectation stated in advance from the applicability rule of the paper: the calibrated self-training should help where the anchored teacher under-detects (zero-shot precision above recall) and be neutral or harmful where it over-predicts; RSR is not expected to help reliably outside SAT→UAV (within-platform pairs, Table A13).

Reporting. Every number is reported whatever its sign, in Section 3.3 and the response letters, with this plan. No configuration is changed and no run is repeated after results are seen; a run that fails for a technical reason (crash, out of memory) is restarted with the identical command, and the failure is recorded.

Amendment (2026-10-22 17:47 JST, before any Bijie run started; requested so that the Bijie test follows exactly the protocol of the external GDCLD check in Table 5 and needs no new protocol description). (1) As for GDCLD, an inductive variant of the full method is added at seed 0 for both transfers (`--uda_mode inductive`: per-subset 50/50 split of the target images into a disjoint adaptation pool and test half; the landslide and non-landslide images are split separately); the anchored source model is scored on the same test half from its per-image counts. (2) The reporting follows Table 5: a seed-0 row per transfer (native source, Source + GSA with zero-shot P/R, GSA + LOC, SCALAR, inductive half, IoU at 0.5 and AP); the seed 1–2 runs give the mean in the text. Nothing else changes.

Amendment 2 (2026-10-22 19:21 JST, before any Bijie run started; replaces the "protocol identical to GDCLD" framing with a protocol set from the properties of the dataset, as decided by the authors). The Bijie images are small, independent crops (61–1239 px, median about 264 × 275 px at 0.8 m), so after anchoring nearly every image is smaller than the 512 px training crop and would be reflect-padded over most of its area (about half at the 0.6 m anchor, about five sixths at the 1 m anchor). For all Bijie adaptation runs the padded target pixels are therefore excluded from the pseudo-label supervision (`--tgt_pad_ignore 1`, the validity mask computed from the image size alone; on CAS this setting changed the five-seed means by +0.1 and +0.3 points, Section 3.2). Everything else stands: anchor and margin rules, transductive adaptation on all 2773 images plus the seed-0 inductive halves, seeds 0–2, the frozen adaptation hyper-parameters, checkpoint selection on the source validation split, inference at 0.5 on the native grid, the outcomes listed above. The paper will describe this in one sentence in Appendix G rather than present the check as identical in protocol to the GDCLD one.

Amendment 3 (2026-10-22 20:20 JST, before any Bijie run started; scheduling only). Seed 0 of both transfers (with the inductive variant) is run first; seeds 1 and 2 follow in a later stage and are reported when available. The protocol and the outcomes are unchanged.
